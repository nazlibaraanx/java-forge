## 🌟 Featured Projects

### 1. VaultX - ATM Console System (`vaultX.java`)
An interactive terminal-based banking system that simulates core financial interactions with active state tracking.

- **Key Implementations:**
  - Continuous transaction cycle using loop control structures.
  - Interactive balance updates for cash deposits and balance inquiries.
  - Overdraft protection and real-time withdrawal validation.
- **Core Concepts:** `while`, Control Flow (`break`), State Mutation, Interactive CLI.

### 2. Grade Average Calculator (`GradeAverageCalculator.java`)
A console application that calculates weighted GPA and passing status based on Midterm, Final, and Quiz inputs.

- **Key Implementations:**
  - Standardized user text inputs using `Scanner` and parsing methods.
  - Weighted average computation: `Midterm (30%) + Final (50%) + Quiz (20%)`.
  - Pass/Fail decision using the inline ternary conditional operator.
- **Core Concepts:** Data Types (`int`, `double`), Type Casting, Arithmetic Operators, Ternary Operator.
